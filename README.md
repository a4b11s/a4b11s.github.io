# Engineer's Toolbox — site

Public pages for the Engineer's Toolbox Android app: privacy policy and landing.

Served via GitHub Pages at `https://a4b11s.github.io/engineers-toolbox/`.

## Publishing

1. Create a **public** GitHub repository named exactly `engineers-toolbox` under the `a4b11s` account.
2. `git push -u origin main`
3. Repository Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. Check `https://a4b11s.github.io/engineers-toolbox/privacy.html` — the app's About screen links to this exact URL.
